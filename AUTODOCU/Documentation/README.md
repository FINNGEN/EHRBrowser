# EHRBrowser

EHR Browser connects to an OMOP-CDM instance and lets you browse the vocabulary graph and visualize how a concept set is constructed and used over time. Given a concept set, it shows its descendants hierarchy, non-standard mappings, and record/person counts over time stratified by sex, age and visit type.
