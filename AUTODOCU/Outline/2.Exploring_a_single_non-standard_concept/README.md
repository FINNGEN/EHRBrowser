# Name

Exploring a single non-Standard Concept

# Description

The EHR Browser also allows to explore non-standard concepts. In the OMOP-CDM jargon a non-standard concept is a medical code that is typically used in national or local setups but when conducting a international study the equivalent Standard concept is used. Exploring the non-standard concepts can help to find mapping errors or understand the concept hierarchy when working in a local study. In this example we will explore non-standard concept ICD10 'Asthma' J45
